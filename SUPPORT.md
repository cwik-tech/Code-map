# Get help with code-map

Start with the [README](README.md). Its section "Questions and problems" gives solutions for the most frequent errors.

If the README does not answer your question:

- To report a bug or ask for a feature, open an issue. Use the issue templates.
- To report a security vulnerability, follow [SECURITY.md](SECURITY.md). Do not open a public issue.
- To contribute a change, read [CONTRIBUTING.md](CONTRIBUTING.md).

code-map is maintained by volunteers. There is no guaranteed response time.
